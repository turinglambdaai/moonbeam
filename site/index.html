agent 时代 · 自建服务器 · 文本车道优先

家里那台机器，一条隧道到家。

UU 远程证明了远程该有的样子：装上、登录、机器就在那里。Moonbeam 把这份体验搬回你自己的硬件—— 信令、中继与远程唤醒跑在你自己的 NAS 或服务器上。agent 用 run 拿确定性 JSON 与真实退出码， 人用终端与文件传输；桌面画面按需调取，复用 Moonlight 生态。

三步开始 查看源码

M0 + M1 已落地并通过三平台 CI：文本车道局域网与外网隧道全通。尚无安装包，当前为源码运行。

三件套，一个目标

Host 管家

常驻 macOS / Windows / Linux：PIN 配对、exec 确定性 JSON verdict、终端会话（pipe / 真 pty）、文件 put/get 带 SHA-1 校验。

Client

agent-first CLI：路由梯子先试局域网直连（硬超时），中继隧道兜底；断线继承让 shell 脱离连接后继续活着，随时 resume。

Relay

单文件零依赖 + Docker：健康检查、信令、远程唤醒（原生 SO_BROADCAST），以及把主机与客户端焊在一起的字节拼接隧道。

刻意不重造视频管线：桌面画面按需调取，复用 Moonlight 生态（Apollo / Sunshine 主机端 + Moonlight 客户端，独立进程驱动）。 Moonbeam 拥有的是其余的全部——隧道、终端、文件、唤醒、配对与编排。

连接梯子，不赌运气

局域网直连优先（1.5 秒硬超时），中继隧道兜底——主机与客户端都向 relay 外呼， relay 把两条连接焊成一根字节管道，任何允许外呼的 NAT 后面都能用，不需要端口转发。 文本车道只有千比特级，走中继毫不心疼；未来视频车道的直连梯级（IPv6 直拨、UDP 打洞）随 M2 交付。

三步开始

需要 Racket 9+（Host 守护进程暂限 macOS / Linux）。

git clone https://github.com/turinglambdaai/moonbeam.git
cd moonbeam
raco pkg install --auto --name moonbeam --link racket

在要被到达的机器上（Host）：

racket racket/moonbeam/host.rkt start             # 会打印配对 PIN

在你的机器上（Client）：

racket racket/moonbeam/client.rkt pair <host> 49090 --pin <NNNNNN>
racket racket/moonbeam/client.rkt run <host> echo hello       # JSON verdict + 真实退出码
racket racket/moonbeam/client.rkt sh <host> --command uptime  # 终端车道
racket racket/moonbeam/client.rkt put <host> ./file.txt       # 文件传输

从局域网外——先把两端指到你的 relay：

racket racket/moonbeam/host.rkt start --relay <relay:8090> --host-id home --relay-token <token>
racket racket/moonbeam/client.rkt use-relay <relay> 8090 <token>
racket racket/moonbeam/client.rkt pair home --pin <NNNNNN> --via
racket racket/moonbeam/client.rkt run home echo hello-from-anywhere

路线图

  • 已完成M0 · 文本车道局域网闭环：配对、exec、终端、文件传输
  • 已完成M1 · relay 拼接隧道：外网可达、断线继承、路由梯子
  • M2 · 桌面画面：装配 Apollo / Sunshine，驱动 Moonlight（办公级调优）+ 视频车道直连梯级（IPv6、UDP 打洞）+ GUI 壳
  • M3 · 完整唤醒体验（NAS 容器 + 云入口）、会话监控、防窥、无线副屏
  • M4 · 家族打包标杆：dmg / msi / deb / rpm / AppImage、更新 feed、产品主页
  • M5+ · iOS / iPadOS / watchOS / Android（等 rivet 移动宿主）
